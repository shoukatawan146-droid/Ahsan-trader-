AHSAN TRADERS — Sanitary Product Price Book

GitHub Pages setup:
1. Create a new repository on GitHub.
2. Upload index.html and logo.png from this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub to publish the site; open the Pages URL shown there.

Important:
- Products are stored in the browser's local storage on each device/browser.
- Data does not automatically sync between devices or browsers.
- Export a backup before clearing browser data.
